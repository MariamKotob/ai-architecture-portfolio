## How to read this repo

| Folder | What's inside |
|---|---|
| [`docs/`](docs/) | One file per session, in order (`01-framing.md`, `02-building-blocks.md`, ...). Start here. |
| [`diagrams/`](diagrams/) | Exported PNG/SVG diagrams, with editable sources in [`diagrams/src/`](diagrams/src/). |
| [`adr/`](adr/) | Architecture Decision Records, one per decision (`0001-model-hosting.md`, ...). |
| [`capstone/`](capstone/) | The final architecture document (PDF) and slides. |

Suggested path: read the **Scenario** above, follow `docs/` in order, look at the ADRs each session links to, then finish with `capstone/`.
